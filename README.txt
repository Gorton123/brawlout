BRAWL OUT - source code

1. Put this folder in your Linux files (so it's at ~/brawlout).
2. In Terminal:
     sudo apt install -y nodejs npm
     cd ~/brawlout
     npm install
     npm run dev
3. Open http://localhost:8000 in Chrome.
4. Open a second Terminal tab:
     cd ~/brawlout
     claude
   Tell Claude what to change. The game reloads by itself.
